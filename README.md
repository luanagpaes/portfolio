## 📋 Sobre o Projeto

Portfolio pessoal desenvolvido com HTML, CSS e JavaScript puro, com foco em **acessibilidade**, **design inclusivo** e **experiência do usuário**. O site apresenta seções de apresentação, tecnologias, projetos e contato — com suporte a dois idiomas e alternância de tema.

## 🚀 Funcionalidades

- **Tema claro/escuro** — alternância com persistência via `localStorage`
- **Internacionalização (i18n)** — suporte completo a Português 🇧🇷 e Inglês 🇺🇸
- **Menu responsivo** — hamburger menu para dispositivos móveis
- **Scroll reveal** — animações de entrada via `IntersectionObserver`
- **Navegação ativa** — destaque automático do link da seção visível
- **Formulário de contato** — com validação em tempo real e feedback de sucesso
- **QR Code WhatsApp** — gerado dinamicamente via biblioteca `qrcodejs`
- **Smooth scroll** — rolagem suave entre seções

## 🎨 Design

O projeto utiliza **CSS custom properties** para suportar os temas claro e escuro de forma elegante, e segue princípios de **design acessível**:

- Contraste adequado entre texto e fundo (WCAG)
- Atributos `aria-label` e `role` nos elementos interativos
- Semântica HTML correta (`<header>`, `<main>`, `<footer>`, `<nav>`, etc.)
- Feedback visual e textual para ações do usuário
